# 🗂️ Master Index

> [!tip] Every note has a number
> Each note has an **ID** like `60.03`. The **two digits before the dot are the section**;
> the digits after the dot are the note within it. `.00` is always the section's hub page.
> To jump to a note, click it below or search its ID (`Ctrl/Cmd + Shift + F` → `60.03`).
> Everything on this page is a plain link, so it works with or without Dataview.

## 🧠 The ten sections
Numbered in the order information moves through the vault:

| ID | Section | Think of it as | Hub |
|----|---------|----------------|-----|
| **00** | Start | the front door | [[Home]] |
| **10** | Inbox | *catch it* | [[Inbox/Inbox\|Inbox]] |
| **20** | Daily | *log it* | [[Daily/Daily\|Daily]] |
| **30** | Projects | *finish it* — has a goal and a deadline | [[Projects/Projects\|Projects]] |
| **40** | Areas | *maintain it* — no end date | [[Areas/Areas\|Areas]] |
| **50** | Resources | *look it up* | [[Resources/Resources\|Resources]] |
| **60** | Notes | *understand it* — one idea per note | [[Notes/Notes\|Notes]] |
| **70** | Maps of Content | *connect it* | [[Maps of Content/Maps of Content\|Maps of Content]] |
| **80** | Memory | ClawAgent's working memory | [[Memory/Memory\|Memory]] |
| **90** | Archive | *done with it* | [[Archive/Archive\|Archive]] |

> [!note] How to remember it
> **Catch → log → finish → maintain → look up → understand → connect → archive.**
> Low numbers are fresh and actionable; higher numbers are settled knowledge; 90 is retired.

| If it's… | File it in | Then |

| something that happened today | **20** Daily | move the keepers somewhere permanent |
| work with a goal and a deadline | **30** Projects | archive it when done |
| an ongoing responsibility | **40** Areas | review it regularly |
| reference you'll want again | **50** Resources | |

## ➕ Adding a note
1. Pick its section using **Where does new stuff go?** above.
2. Give it the next free number in that section — the next permanent note is **60.06**.
3. Fill in `id: "60.06"` in its frontmatter (keep the quotes) and add a row to the table above.
4. When you archive something, move it to `Archive/` and list it under **90**, but keep its old ID
   so you can still find it by the number you remember.

Daily notes and the agent's `Memory/` notes don't need IDs.

```dataview

FROM ""
WHERE !id AND type != "daily" AND file.name != "README" AND !contains(file.folder, "Templates") AND !contains(file.folder, "Memory")

```

### Recently updated
```dataview
TABLE id, type, file.mtime AS "Modified"
FROM ""
WHERE file.name != "Index"
SORT file.mtime DESC
LIMIT 15
```

### Loose ends (nothing links here)
```dataview

FROM ""
WHERE length(file.inlinks) = 0 AND type != "dashboard" AND type != "index"
SORT file.name ASC
```
